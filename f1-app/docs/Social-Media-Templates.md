# Social Media Content Templates

Use these templates after every race to drive traffic back to openf1ow.com.

## Twitter/X Templates

### Post-Race Thread (3-5 tweets)
```
Tweet 1/4:
🏁 [Year] [GP Name] — Race Analysis
• [Key stat #1, e.g. "Max gained 3.2s in Sector 2 after pit window"]
• [Key stat #2, e.g. "Leclerc's tire deg was 0.15s/lap worse than Norris"]
• Full telemetry + engine analysis → openf1ow.com/[year]/[mk]/[sk]/analysis/overview
📊 [Attach SocialShareCard image]

Tweet 2/4:
🔋 TIRE STRATEGY BREAKDOWN
[Paste a specific tire deg insight from the tire degradation tab]

Tweet 3/4:
⚡ SECTOR ANALYSIS
[Paste a sector-specific insight — who was fastest in which sector and why]

Tweet 4/4:
🏎️ ENGINE VERDICT
[Paste the engine-computed race analysis summary — it's already great content]

All analysis powered by OpenF1ow — free, open-source F1 telemetry.
```

### Quick Stat Card
```
📊 [Year] [GP Name] — [Driver]
[One specific stat: "Fastest lap by [X]s", "Most consistent sector: Sector 2, 47 laps"]

Full telemetry → openf1ow.com/[year]/[mk]
```

### Before Race (Teaser)
```
🏎️ [Year] [GP Name] this weekend!

Pre-race analysis coming to openf1ow.com:
• Tire strategy projections
• Sector-based pace rankings
• Historical comparison to [past similar race]

```

## Reddit Templates

### Post Title Options
- "[Analysis] [GP Name] — [driver] won despite [strategic call]"
- "I analyzed every lap of the [GP Name] — here's what the data shows"
- "F1 telemetry breakdown: Why [driver] was actually faster than results show"

### Post Body Template
```markdown
## [GP Name] — Telemetry Analysis

**Session:** [Qualifying/Race]  
**Date:** [date]  
**Source:** [openf1ow.com link]

### Key Findings

1. **Pace Comparison** — [Driver A] was [X]s faster in Sector [N] despite [reason]
2. **Tire Degradation** — [Compound] lasted [X] laps with [Y]s/lap deg
3. **Strategy** — [Driver] gained [Z]s with the [undercut/overcut] window at lap [N]

### The Data

[Embed SocialShareCard image or link to analysis page]

Full interactive analysis: [openf1ow.com link]

*Built with the OpenF1 API — completely free and open-source.*
```

**Best subreddits:** r/F1, r/formula1, r/Motorsport, r/[DriverTeam] specific subs

## Facebook Groups

Use the Reddit template but shorten it. Facebook F1 groups respond best to:
- One striking stat with a visual
- A question to engage comments: "Do you agree with this strategy call?"
- Link to openf1ow.com in the first comment (not the post body)

## Instagram Stories

1. Take the SocialShareCard image
2. Add overlay text: "Did you know [stat]?"
3. Link sticker → openf1ow.com/[year]/[mk]

## Key Growth Tactics

1. **Post within 2 hours of chequered flag** — this is when F1 social engagement peaks
2. **Tag relevant drivers/teams** — they sometimes share fan content
3. **Use hashtags**: #F1 #[Year]#[GPName] #[DriverName] #Formula1 #F1Telemetry
4. **Cross-post the same insight** to Reddit, X, and Facebook (but adapt the format for each)
5. **Include the SocialShareCard image** — visual content gets 3-5x more engagement
